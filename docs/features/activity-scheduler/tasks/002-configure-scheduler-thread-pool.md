## Goal

Configure a custom TaskScheduler thread pool with a pool size of 1 and thread name prefix `activity-scheduler-` using Spring Boot Task Scheduling.

## Context

By default, Spring Boot uses a single-threaded TaskScheduler, but we must configure it explicitly to set the thread name prefix to `activity-scheduler-` for thread isolation, monitoring, and debugging.

## Scope

- Create package `com.lucasbdourado.autotimemarking.modules.scheduler.infrastructure.config`.
- Create a configuration class `SchedulerConfig` decorated with `@Configuration` and `@EnableScheduling`.
- Register a `TaskScheduler` bean (or customize the Spring TaskScheduler) to enforce a pool size of 1 and set the thread name prefix to `activity-scheduler-`.

## Out of Scope

- Implementing the scheduled component runner itself.
- Setting up the timezone-aware date filter.
